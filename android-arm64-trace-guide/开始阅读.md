## 📦 需要下载什么？

### 快速参考

**使用 Frida + QBDI（推荐）:**
```bash
# 下载主包（~20 MB）
wget https://github.com/QBDI/QBDI/releases/download/v0.12.0/QBDI-0.12.0-android-AARCH64.tar.gz

# 解压
tar -xzf QBDI-0.12.0-android-AARCH64.tar.gz
```

**使用 PyQBDI:**
```bash
# 下载对应 Python 版本的 wheel（~5 MB）
wget https://github.com/QBDI/QBDI/releases/download/v0.12.0/pyqbdi-0.12.0-cp311-cp311-linux_aarch64.whl

# 安装
pip install pyqbdi-0.12.0-cp311-cp311-linux_aarch64.whl
```

**详细说明**: 查看 [文件说明.md](./文件说明.md)

## ✅ 环境检查

在开始之前，请确认:

**Android 设备:**
- [ ] ARM64 (arm64-v8a) 架构
- [ ] Android 7.0+ (API 24+)
- [ ] 已 root（推荐）
- [ ] USB 调试已启用

**开发机器:**
- [ ] 已安装 ADB
- [ ] 可以连接到 Android 设备

检查命令:
```bash
adb devices
adb shell getprop ro.product.cpu.abi
# 应该输出: arm64-v8a
```
