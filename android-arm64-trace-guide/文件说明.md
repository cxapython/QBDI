## 🎯 不同使用方式需要的文件

### 方式一: Frida + QBDI（推荐）

**需要下载:**
- ✅ QBDI-0.12.0-android-AARCH64.tar.gz

**需要使用的文件:**
- `lib/libQBDI.so` - 推送到 Android 设备
- `share/qbdi/frida-qbdi.js` - 在开发机器上使用

**额外需要:**
- frida-tools (pip install frida-tools)
- frida-server (从 Frida releases 下载)
- frida-compile (npm install -g frida-compile)

### 方式二: PyQBDI

**需要下载:**
- ✅ pyqbdi-0.12.0-cpXXX-cpXXX-linux_aarch64.whl (选择对应 Python 版本)

**说明:**
- Wheel 包已包含所有需要的文件
- 无需额外下载 libQBDI.so
- 直接 pip install 即可

**额外需要:**
- Android 设备上需要安装 Python (建议使用 Termux)

### 方式三: Native C/C++

**需要下载:**
- ✅ QBDI-0.12.0-android-AARCH64.tar.gz

**需要使用的文件:**
- `lib/libQBDI.so` - 链接库
- `include/QBDI/*` - 开发头文件

**额外需要:**
- Android NDK (如果需要编译)
- CMake 和编译工具链

## 📱 设备上需要的文件

### Frida + QBDI 方式

**在 Android 设备上:**
```
/data/local/tmp/
├── frida-server              # Frida 服务端
└── libQBDI.so                # QBDI 库
```

**在开发机器上:**
```
your-project/
├── frida-qbdi.js             # 从 QBDI 包复制
├── your_script.js            # 你的脚本
└── your_script_compiled.js   # 编译后的脚本
```

### PyQBDI 方式

**在 Android 设备上 (Termux):**
```
# PyQBDI 通过 pip 安装到 Python 环境
~/.local/lib/python3.x/site-packages/pyqbdi/

# 你的脚本可以放在任何位置
/sdcard/your_script.py
```

## 🔍 文件详细说明

### libQBDI.so

**完整路径:** `lib/libQBDI.so`

**属性:**
- 大小: ~15 MB
- 架构: ARM64 (aarch64)
- API Level: 24+ (Android 7.0+)
- 编译方式: RelWithDebInfo (包含调试符号)

**包含组件:**
- QBDI 核心引擎
- LLVM JIT 编译器
- ARM64 指令分析器
- 内存管理器
- 执行块管理器

**使用位置:**
- 必须推送到 Android 设备
- 推荐路径: `/data/local/tmp/`
- 权限: 644 (rw-r--r--)

### frida-qbdi.js

**完整路径:** `share/qbdi/frida-qbdi.js`

**属性:**
- 大小: ~100 KB
- 格式: JavaScript ES2019
- Frida 版本要求: >= 14.0

**提供的 API:**
- VM 类: QBDI 虚拟机
- 回调类型: InstCallback, MemCallback, VMCallback
- 枚举: VMAction, InstPosition, MemoryAccess 等
- 工具函数: 地址转换、状态操作等

**使用位置:**
- 在开发机器上
- 需要用 frida-compile 编译
- 通过 import 导入到你的脚本

### PyQBDI Wheel

**文件格式:** `.whl` (Wheel 格式)

**包含内容:**
- pyqbdi Python 模块
- libQBDI.so (已编译)
- Python 绑定层
- 类型定义

**安装后位置:**
```python
import pyqbdi
print(pyqbdi.__file__)
# 输出: /path/to/site-packages/pyqbdi/__init__.py
```

## ❓ 常见问题

### Q: 需要下载所有 PyQBDI wheel 包吗？

**A:** 不需要。只需要下载与你的 Python 版本匹配的一个包。

检查 Python 版本:
```bash
python3 --version
# Python 3.11.x -> 下载 cp311 版本
```

### Q: libQBDI.so 可以放在其他位置吗？

**A:** 可以，但需要注意:
- `/data/local/tmp/` - 推荐，所有应用都可访问
- `/system/lib64/` - 需要 root，需要重新挂载系统分区
- 应用私有目录 - 需要对应应用权限

使用 `LD_LIBRARY_PATH` 指定:
```bash
LD_LIBRARY_PATH=/your/path ./your_app
```

### Q: 如何更新到新版本？

**A:** 
1. 下载新版本的包
2. 替换设备上的 libQBDI.so
3. 更新 frida-qbdi.js
4. 重新编译你的脚本
