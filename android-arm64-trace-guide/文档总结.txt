================================================================================
  技术要求
================================================================================

【Android 设备】
   - 架构: ARM64 (arm64-v8a)
   - 系统: Android 7.0+ (API 24+)
   - Root: 推荐（某些功能需要）
   - USB 调试: 必需

【开发机器】
   - ADB: 必需
   - Python 3.x: PyQBDI 方式需要
   - Node.js + npm: Frida 方式需要
   - Android NDK: 编译方式需要

================================================================================
  快速开始命令
================================================================================

# 1. 下载预编译包
wget https://github.com/QBDI/QBDI/releases/download/v0.12.0/QBDI-0.12.0-android-AARCH64.tar.gz
tar -xzf QBDI-0.12.0-android-AARCH64.tar.gz

# 2. 部署到设备
adb push QBDI-0.12.0-android-AARCH64/lib/libQBDI.so /data/local/tmp/
adb shell chmod 644 /data/local/tmp/libQBDI.so

# 3. 安装 Frida
pip install frida-tools
npm install -g frida-compile

# 4. 开始使用
# 详见 快速开始-使用预编译包.md
