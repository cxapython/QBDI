# QBDI Android ARM64 快速开始指南（使用预编译包）

**无需编译,直接使用!**

本指南将教你如何使用 QBDI 官方预编译包在 ARM64 架构的 Android 设备上进行 trace。

## 📦 第一步：下载预编译包

### 访问 QBDI Releases 页面

**最新版本**: QBDI 0.12.0 (2024-10-14)

**下载地址**: https://github.com/QBDI/QBDI/releases/tag/v0.12.0

### Android ARM64 需要下载的文件

根据你的使用方式,选择下载对应的文件:

#### 1️⃣ 使用 Frida + QBDI（推荐,最简单）

下载以下文件:

- **QBDI-0.12.0-android-AARCH64.tar.gz**
  - 大小: ~20 MB
  - SHA256: `查看 image.hash 文件`
  - 包含内容:
    - `libQBDI.so` - QBDI 核心库
    - `frida-qbdi.js` - Frida 绑定脚本
    - 头文件和文档

**下载命令:**
```bash
# 下载主包
wget https://github.com/QBDI/QBDI/releases/download/v0.12.0/QBDI-0.12.0-android-AARCH64.tar.gz

# 解压
tar -xzf QBDI-0.12.0-android-AARCH64.tar.gz
cd QBDI-0.12.0-android-AARCH64
```

#### 2️⃣ 使用 PyQBDI（Python 方式）

下载对应的 Python wheel 包:

- **pyqbdi-0.12.0-cp310-cp310-linux_aarch64.whl** (Python 3.10)
- **pyqbdi-0.12.0-cp311-cp311-linux_aarch64.whl** (Python 3.11)
- **pyqbdi-0.12.0-cp312-cp312-linux_aarch64.whl** (Python 3.12)
- **pyqbdi-0.12.0-cp313-cp313-linux_aarch64.whl** (Python 3.13)

选择与你的 Python 版本对应的包。

**注意**: 这些 wheel 包是为 Linux ARM64 设计的,可以在 Android (基于 Linux 内核) 上使用。

**安装命令:**
```bash
# 检查 Python 版本
python3 --version

# 下载对应版本的 wheel (以 Python 3.11 为例)
wget https://github.com/QBDI/QBDI/releases/download/v0.12.0/pyqbdi-0.12.0-cp311-cp311-linux_aarch64.whl

# 安装
pip3 install pyqbdi-0.12.0-cp311-cp311-linux_aarch64.whl
```

## 📱 方式一：使用 Frida + QBDI（推荐）

### 1. 安装 Frida

#### 在电脑上安装 Frida 工具

```bash
pip3 install frida-tools
frida --version
```

#### 下载并部署 frida-server

```bash
# 访问 https://github.com/frida/frida/releases
# 下载对应版本的 frida-server-*-android-arm64.xz
# 注意: frida-tools 和 frida-server 版本要匹配!

# 示例（根据你的 Frida 版本调整）
wget https://github.com/frida/frida/releases/download/16.5.9/frida-server-16.5.9-android-arm64.xz

# 解压
xz -d frida-server-16.5.9-android-arm64.xz

# 推送到设备
adb push frida-server-16.5.9-android-arm64 /data/local/tmp/frida-server
adb shell chmod 755 /data/local/tmp/frida-server

# 启动 frida-server（保持运行）
adb shell su -c "/data/local/tmp/frida-server &"
```

### 2. 部署 QBDI

```bash
# 解压 QBDI 包（如果还没解压）
tar -xzf QBDI-0.12.0-android-AARCH64.tar.gz
cd QBDI-0.12.0-android-AARCH64

# 推送 libQBDI.so 到设备
adb push lib/libQBDI.so /data/local/tmp/

# 设置权限
adb shell chmod 644 /data/local/tmp/libQBDI.so

# 复制 frida-qbdi.js 到工作目录
cp share/qbdi/frida-qbdi.js ./
```

### 3. 编写 Frida 脚本

创建 `trace_app.js`:

```javascript
import { VM, InstPosition, VMAction } from "./frida-qbdi.js";

console.log("[*] Script loaded");

// 等待应用启动
setTimeout(function() {
    console.log("[*] Initializing QBDI...");
    
    // 初始化 QBDI VM
    var vm = new VM();
    console.log("[*] QBDI version: " + vm.version.string);
    
    // 示例1: Trace 特定函数
    // 替换为你要 trace 的函数名
    var targetModule = "libnative-lib.so";
    var targetFunction = "Java_com_example_app_MainActivity_nativeMethod";
    
    var funcAddr = Module.findExportByName(targetModule, targetFunction);
    
    if (funcAddr) {
        console.log("[*] Found function at: " + funcAddr);
        
        // 添加整个模块到监控范围
        vm.addInstrumentedModule(targetModule);
        
        // 定义指令回调
        var instCallback = vm.newInstCallback(function(vm, gpr, fpr, data) {
            var inst = vm.getInstAnalysis();
            console.log("  0x" + inst.address.toString(16) + ": " + inst.disassembly);
            return VMAction.CONTINUE;
        });
        
        // 注册回调
        vm.addCodeCB(InstPosition.PREINST, instCallback, null);
        
        // Hook 函数入口
        Interceptor.attach(funcAddr, {
            onEnter: function(args) {
                console.log("\n[+] Function called!");
                console.log("[*] Args: x0=" + args[0] + ", x1=" + args[1]);
                
                // 获取当前上下文
                var state = vm.getGPRState();
                state.pc = ptr(funcAddr);
                state.sp = this.context.sp;
                
                // 复制寄存器
                for (var i = 0; i < 29; i++) {
                    state["x" + i] = this.context["x" + i];
                }
                state.fp = this.context.x29;
                state.lr = this.context.x30;
                
                vm.setGPRState(state);
                
                console.log("[*] Starting instruction trace...\n");
                // 运行 trace
                vm.run(funcAddr, ptr(0xffffffffffffffff));
            },
            onLeave: function(retval) {
                console.log("\n[*] Function returned: " + retval);
            }
        });
        
        console.log("[*] Hook installed, waiting for function call...");
    } else {
        console.error("[!] Function not found!");
        
        // 示例2: 列出模块导出函数
        console.log("\n[*] Available exports in " + targetModule + ":");
        var module = Process.getModuleByName(targetModule);
        module.enumerateExports().slice(0, 10).forEach(function(exp) {
            console.log("  - " + exp.name + " @ " + exp.address);
        });
    }
    
}, 1000);
```

### 4. 编译和运行

```bash
# 安装 frida-compile
npm install -g frida-compile

# 编译脚本
frida-compile trace_app.js -o trace_app_compiled.js

# 注入到正在运行的应用
frida -U -n com.example.app -l trace_app_compiled.js

# 或者启动应用并注入
frida -U -f com.example.app -l trace_app_compiled.js --no-pause
```

### 5. 更简单的示例 - Trace 系统库函数

创建 `trace_libc.js`:

```javascript
import { VM, InstPosition, VMAction } from "./frida-qbdi.js";

console.log("[*] Tracing libc functions...");

var vm = new VM();
console.log("[*] QBDI version: " + vm.version.string);

// Trace strlen 函数
var strlen = Module.findExportByName("libc.so", "strlen");

if (strlen) {
    console.log("[*] Found strlen at: " + strlen);
    
    vm.addInstrumentedModuleFromAddr(strlen);
    
    var instCallback = vm.newInstCallback(function(vm, gpr, fpr, data) {
        var inst = vm.getInstAnalysis();
        console.log("  0x" + inst.address.toString(16) + ": " + inst.disassembly);
        return VMAction.CONTINUE;
    });
    
    vm.addCodeCB(InstPosition.PREINST, instCallback, null);
    
    Interceptor.attach(strlen, {
        onEnter: function(args) {
            var str = args[0].readUtf8String();
            console.log("\n[+] strlen(\"" + str + "\")");
            console.log("[*] Tracing instructions:\n");
            
            var state = vm.getGPRState();
            state.x0 = args[0];
            state.pc = ptr(strlen);
            state.sp = this.context.sp;
            vm.setGPRState(state);
            
            vm.run(strlen, ptr(0xffffffffffffffff));
        },
        onLeave: function(retval) {
            console.log("\n[*] Result: " + retval + "\n");
        }
    });
    
    console.log("[*] Hook installed!");
}
```

编译运行:

```bash
frida-compile trace_libc.js -o trace_libc_compiled.js
frida -U -f com.example.app -l trace_libc_compiled.js --no-pause
```

### 3. 编写 Python 脚本

创建 `trace_demo.py`:

```python
#!/usr/bin/env python3

import sys
import pyqbdi
import ctypes

def instruction_callback(vm, gpr, fpr, data):
    """每条指令执行前的回调"""
    inst = vm.getInstAnalysis()
    print(f"0x{inst.address:x}: {inst.disassembly}")
    return pyqbdi.CONTINUE

def trace_function(lib_path, func_name):
    """Trace 指定库的指定函数"""
    
    print(f"[*] Loading library: {lib_path}")
    lib = ctypes.CDLL(lib_path)
    
    print(f"[*] Finding function: {func_name}")
    func = getattr(lib, func_name)
    func_ptr = ctypes.cast(func, ctypes.c_void_p).value
    
    print(f"[*] Function address: 0x{func_ptr:x}")
    
    # 初始化 QBDI VM
    print("[*] Initializing QBDI VM...")
    vm = pyqbdi.VM()
    
    # 创建栈空间
    state = vm.getGPRState()
    stack = pyqbdi.allocateVirtualStack(state, 0x100000)
    
    # 添加监控模块
    vm.addInstrumentedModuleFromAddr(func_ptr)
    
    # 注册指令回调
    vm.addCodeCB(pyqbdi.PREINST, instruction_callback, None)
    
    # 记录内存访问
    vm.recordMemoryAccess(pyqbdi.MEMORY_READ_WRITE)
    
    # 设置参数 (示例: strlen)
    if func_name == "strlen":
        test_str = b"Hello QBDI!\x00"
        str_ptr = ctypes.create_string_buffer(test_str)
        str_addr = ctypes.addressof(str_ptr)
        state.x0 = str_addr
        print(f"[*] Test string: {test_str.decode('utf-8', errors='ignore')}")
    
    # 模拟函数调用
    pyqbdi.simulateCall(state, 0xdeadbeef)
    
    # 运行 trace
    print("[*] Starting trace...\n")
    success = vm.run(func_ptr, 0xdeadbeef)
    
    print(f"\n[*] Trace {'succeeded' if success else 'failed'}")
    
    # 清理
    pyqbdi.alignedFree(stack)

if __name__ == "__main__":
    # 示例: trace libc 的 strlen 函数
    trace_function("/system/lib64/libc.so", "strlen")
```

### 4. 运行

```bash
# 推送脚本到设备

# 在设备上运行
adb shell "cd /data/local/tmp && python3 trace_demo.py"

# 或在 Termux 中运行
# (在 Android 设备上)
```

## 📊 实战示例：Trace Android 应用

### 完整示例：追踪加密函数

假设你想追踪一个应用中的加密函数 `AES_encrypt`:

**1. 创建脚本 `trace_aes.js`:**

```javascript
import { VM, InstPosition, VMAction, MemoryAccess } from "./frida-qbdi.js";

console.log("[*] AES Encryption Tracer");

var vm = new VM();
console.log("[*] QBDI version: " + vm.version.string);

// 查找目标模块
var targetModule = "libcrypto.so"; // 或者你的应用的 native 库
var targetFunction = "AES_encrypt";

var funcAddr = Module.findExportByName(targetModule, targetFunction);

if (funcAddr) {
    console.log("[*] Found " + targetFunction + " at: " + funcAddr);
    
    vm.addInstrumentedModuleFromAddr(funcAddr);
    
    // 指令回调
    var instCallback = vm.newInstCallback(function(vm, gpr, fpr, data) {
        var inst = vm.getInstAnalysis();
        console.log("  0x" + inst.address.toString(16) + ": " + inst.disassembly);
        return VMAction.CONTINUE;
    });
    
    // 内存访问回调
    var memCallback = vm.newMemCallback(function(vm, access, address, size, value, gpr, fpr, data) {
        var accessType = (access === MemoryAccess.MEMORY_READ) ? "READ" : "WRITE";
        console.log("  [MEM " + accessType + "] 0x" + address.toString(16) + 
                   " (" + size + " bytes) = 0x" + value.toString(16));
        return VMAction.CONTINUE;
    });
    
    vm.addCodeCB(InstPosition.PREINST, instCallback, null);
    vm.addMemAccessCB(MemoryAccess.MEMORY_READ_WRITE, memCallback, null);
    vm.recordMemoryAccess(MemoryAccess.MEMORY_READ_WRITE);
    
    Interceptor.attach(funcAddr, {
        onEnter: function(args) {
            console.log("\n[+] AES_encrypt called");
            console.log("[*] Input data: " + args[0]);
            console.log("[*] Output buffer: " + args[1]);
            console.log("[*] Key: " + args[2]);
            
            // 显示输入数据
            console.log("\n[*] Input data (16 bytes):");
            console.log(hexdump(args[0], { length: 16 }));
            
            console.log("\n[*] Starting trace...\n");
            
            var state = vm.getGPRState();
            state.x0 = args[0];
            state.x1 = args[1];
            state.x2 = args[2];
            state.pc = ptr(funcAddr);
            state.sp = this.context.sp;
            vm.setGPRState(state);
            
            vm.run(funcAddr, ptr(0xffffffffffffffff));
        },
        onLeave: function(retval) {
            console.log("\n[*] Function returned");
        }
    });
    
    console.log("[*] Tracer ready!");
} else {
    console.error("[!] Function not found!");
}
```

**2. 编译运行:**

```bash
frida-compile trace_aes.js -o trace_aes_compiled.js
frida -U -f com.target.app -l trace_aes_compiled.js --no-pause
```

## 🔧 常见问题排查

### 问题 1: libQBDI.so 加载失败

```bash
# 确认文件存在
adb shell ls -l /data/local/tmp/libQBDI.so

# 检查权限
adb shell chmod 644 /data/local/tmp/libQBDI.so

# 如果还不行，尝试推送到其他位置
adb push lib/libQBDI.so /data/local/tmp/
```

### 问题 2: Frida 连接失败

```bash
# 检查 frida-server 是否运行
adb shell ps | grep frida

# 重启 frida-server
adb shell su -c "killall frida-server"
adb shell su -c "/data/local/tmp/frida-server &"

# 检查版本匹配
frida --version
adb shell /data/local/tmp/frida-server --version
```

### 问题 3: SELinux 阻止

```bash
# 临时关闭 SELinux
adb shell su -c "setenforce 0"

# 验证
adb shell getenforce
# 应输出: Permissive
```

### 问题 4: 应用无法启动

```bash
# 检查应用包名
adb shell pm list packages | grep your.app

# 使用正确的包名
frida -U -f com.correct.package.name -l script.js --no-pause
```
